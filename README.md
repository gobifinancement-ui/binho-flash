# Binho Flash

Recharges et retraits 1xBet / Melbet via Mobile Money, suivi des demandes en temps réel et pronostics chaque jour.

## Télécharger l'application Android

👉 **[Télécharger la dernière version (APK)](https://github.com/gobifinancement-ui/binho-flash/releases/latest/download/binho-flash.apk)**

Site : https://binhoflash.onrender.com

### Installation
1. Téléchargez le fichier `binho-flash.apk` depuis votre téléphone.
2. Ouvrez-le. Si Android le demande, autorisez l'installation depuis cette source.
3. Ouvrez Binho Flash et créez votre compte.

Les mises à jour s'installent ensuite depuis l'application.
